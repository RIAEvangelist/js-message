Integration suite · 10 shared checks

Make every entry point agree.

Integration checks connect package exports, the CommonJS identity marker, supported direct paths, and the classic browser global without restating lower-level behavior.

js-message works with bundlers and without a bundler.

Bundlers resolve the bare js-message import normally. Native browser ESM resolves it through a standard import map, with no build or transpilation step.

Repository boundary gates

  • Real Chrome runs the shared catalog against the same shipped source as Node.
  • The live playground is exercised through its frame, editor controls, worker, and visible output.
  • The local documentation server verifies routes, module headers, and security policies.
  • A packed tarball is installed in a clean project and checked through every declared export.
Two layers of integration evidence.

The ten shared IDs remain portable between Node and Chrome. The twelve INT-BROWSER cases and other environment-specific gates stay separate so their setup does not masquerade as duplicate protocol coverage.
